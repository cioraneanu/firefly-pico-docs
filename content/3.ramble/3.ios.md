An iOS you can make this process faster by creating a Shortcut and calling it via the Action button, Lock Screen, Home Screen, Siri, or an Apple Watch. 

You then just describe the transaction.

## Choose a shortcut

**Firefly-Pico** includes two ready-made templates:

- [Text shortcut](https://github.com/cioraneanu/firefly-pico/raw/main/docs/siri-shortcuts/pico-text-template-signed.shortcut): Apple converts your speech to text before sending it. This only requires Ramble's language model configuration.
- [Voice shortcut](https://github.com/cioraneanu/firefly-pico/raw/main/docs/siri-shortcuts/pico-voice-template-signed.shortcut): the recording is uploaded directly. This is faster to capture and can support languages that Apple dictation does not, but it requires Pico's audio transcription service.

These correspond to the two modes described in the [Ramble API reference](/features/ramble/api).

## Install a shortcut

1. Download the text or voice shortcut on your iPhone.
2. Open it in the Shortcuts app and select **Add Shortcut**.
3. Edit the shortcut and replace the Pico URL with your instance URL, for example `https://pico.example.com`.
4. Replace the authorization value with `Bearer ` followed by your Firefly III personal access token.
5. Run the shortcut once and allow the requested microphone or network permissions.

::warning
The shortcut contains your Firefly III token. Do not share or publish the configured shortcut. If the device or shortcut is compromised, revoke the token in Firefly III.
::

## Make it easy to launch

You can assign the shortcut to:

- the Action button on supported iPhones;
- a Lock Screen widget;
- a Home Screen icon;
- a Siri phrase;
- an Apple Watch complication.

Older iPhones without an Action button can use any of the other launch methods.
